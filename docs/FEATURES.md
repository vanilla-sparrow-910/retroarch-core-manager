# RetroArch Core Manager — feature reference

RetroArch Core Manager uses a concise workspace for core categories, content directories, and input profiles. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Core categories | Content and resource groups, together with their configuration or organization details. |
| Content directories | Content and resource groups, together with their configuration or organization details. |
| Input profiles | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
